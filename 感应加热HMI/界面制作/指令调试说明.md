## 双向帧格式

| 方向与类型 | 格式 | 用途 |
| --- | --- | --- |
| 主控 → 屏幕 | ASCII 指令 + 三个二进制 FF | 更新变量、查询和通知屏幕消费输入 |
| 屏幕 → 主控，触摸松开 | `65 PP CC 00 FF FF FF` | PP 是源页面，CC 是控件编号；只报告触摸 |
| 屏幕 → 主控，业务请求 | `A5 5A 01 PP QQ FF FF FF` | 只有通过屏幕本地校验的业务才发送 |
| 屏幕 → 主控，数字确认 | `A5 5A 02 PP II VV VV VV VV FF FF FF` | II 是参数编号，VV 是四字节小端有符号数 |
| 数值查询应答 | `71 VV VV VV VV FF FF FF` | 不带变量名，同一时刻只允许一个未完成查询 |
| 页面查询应答 | `66 PP FF FF FF` | `sendme` 返回当前页；主控用于心跳 |

不能以遇到第一个 `FF FF FF` 直接切分所有回包：负数或普通数值中也可能包含 FF。解析器按帧类型和固定长度识别。数字编辑帧表示编辑完成，不代表主控已经应用或保存。

110204 起，分段页插入/删除温段及切换算法另发送字段号 `II=0` 的类型 02 帧，表示方案结构发生编辑；主控会取消尚未完成的方案读取，避免混合编辑前后的参数。字段号 0 不是数字键盘参数。

屏幕按钮同时发送触摸帧和业务帧时，主控只按业务帧执行一次。不要再轮询 `cmd` 执行第二遍。页面、控件、字段的完整映射以 `V9/串口事件映射.json` 为准。

| 页面 / 请求号 | 操作 | 当前主控行为 |
| --- | --- | --- |
| 0 / 1 | 启动加热 | 读取用户搜频范围，从上限软启动；保持临时调功角搜频和锁相，不自动加大移相 |
| 任意正常页 / 2 | 停止加热 | 关闭驱动和输出，保留旁路继电器 |
| 1 / 3 | 应用温控参数 | 完整读取段数、算法、功率上限和 12 段目标/时长，校验后原子应用至 RAM；总览与曲线显示首段目标 |
| 3 / 3 | 应用功率设置 | 读取功率上限并应用到 RAM；不启动功率闭环或限功率 |
| 1 / 4 | 保存温控方案 | 中文提示尚未接入，不报告成功 |
| 5 / 4 | 保存保护参数 | 顺序读取六项阈值，校验后保存至 Flash |
| 4 / 5 | 搜频并启动 | 停止状态读取上下限后开始搜频锁相，运行时需先停止 |
| 5 / 6 | 故障复位 | 故障恢复、采样通信正常且稳定 200 ms 后解除锁存；不会自动重新启动 |
| 5 / 7 | 确认报警 | 确认记录，保护锁存仍保留 |

总览启动帧示例：

```text
65 00 26 00 FF FF FF
A5 5A 01 00 01 FF FF FF
```

屏幕显示“请求已发送；等待主控”只代表请求发出。主控回传的运行状态、报警及中文回执才表示处理结果。

## 中文提示由屏幕生成

主控不再改写 `tFoot.txt` 或 `tAlarm.txt`。提示文本保存在 `feedback_messages.json`，编号从 1 开始，与 `Core/Inc/ih_hmi_messages.h` 保持一致。生成器和测试会核对两端编号。文本存入屏幕工程时使用 GB2312/GBK，主控只发送数字，不受 STM32 C 文件编码影响。

| 变量 | 含义 |
| --- | --- |
| `msgCode` | 提示编号 |
| `msgA`、`msgB` | 数字参数；欠压提示中分别为触发电压 × 10、欠压门限 V |
| `msgPush` | 置 1 提交一次提示，屏幕消费后清零 |
| `internalFault` | 主控 ADC、母线数据、通信等内部故障位；保护页本地显示“采样或通信异常” |

例如在串口屏模拟器当前正常页面依次输入：

```text
msgCode=10
msgA=170
msgB=18
msgPush=1
click bInput,0
```

页面底部显示“本次欠压：17.0V，门限18V，请复位”。提示编号 32 使用相同数值参数显示“上次欠压”，用于说明故障未复位而导致的启动拒绝；这不是一次新的保护触发。这是显示接口调试例子，不会制造或解除主控的实际欠压状态。通过外部 UART 发送时，每条命令后都要追加三个二进制 FF；模拟器输入区无需手工追加。

主控还保留 `dbg_trip_bus_v`、`dbg_trip_uv_v`、`dbg_trip_bus_raw`、`dbg_trip_bus_tick` 和 `dbg_trip_elapsed_ms` 供 Watch 查看。欠压提示的电压取自触发快照，不能用随后恢复的屏幕电压否定曾发生过低压采样。

## 遥测字段和独立有效性

先更新数据和 `dataFlags`，最后置 `dirty=1` 并触发 `bInput`。测量字段刷新与曲线绘制分开，`push/sampleSec` 不再驱动屏幕短缓存。HMI 定时器和 `bInput` 使用同一套渲染逻辑；主控不应再直接改写测量标签，避免 `--` 与 0 交替出现。

| 有效位值 | 字段 | 单位 / 当前状态 |
| --- | --- | --- |
| 1 | `temp10` | 串口工件温度 × 10；只接受 USART2 协议验证后的温度，不使用 ADC 代替 |
| 2 | `target10` | RAM 中已应用的首段目标温度 × 10；默认 60℃，应用后更新，不表示温控已执行 |
| 4 | `power100` | 带符号有功功率 W × 100；24 显示 0.24W，-1240 显示 -12.40W；待实板标定 |
| 8 | `bus10` | 母线电压 V × 10 |
| 16 | `amp10` | 去除实测直流均值的谐振电流 RMS A × 10；要求显式配置已接 CT 且 ADC 新鲜有效 |
| 32 | `freq100` | 配置频率 kHz × 100；2010 显示 20.10 kHz |
| 64 | `phase10` | 谐振基波相位差 × 10；启动且相位采样有效才置位，电压超前电流为正 |
| 128 | `mean10` / `high10` / `low10` | 串口区域平均/最高/最低温度 × 10；整组校验有效才显示 |
| 256 | `angle10` | PWM 请求移相角 × 10，功率页显示；与谐振相位分开 |
| 512 | `temp110` | PA2 器件一温度 × 10；连接并标定后才有效 |
| 1024 | `temp1mv` / `temp2mv` | PA2/PA3 引脚电压 mV，仅供调试/未来保护接口，界面不再显示，和摄氏度有效性独立 |
| 2048 | `temp210` | PA3 器件二温度 × 10；连接并标定后才有效 |

无效字段稳定显示 `--`。只给总标志 `valid=1` 不会使 V9 的所有通道有效。历史点也保存独立有效位，无效点不画零曲线，不跨失效区间连线。

下面是总览 / 频率曲线的模拟输入例子，仅用于验证界面：

```text
dirty=0
bus10=240
amp10=12
freq100=2010
dataFlags=56
dirty=1
click bInput,0
```

本例只使母线、电流、频率字段显示 24.0V、1.2A、20.10kHz，其余字段为 `--`；不会自动产生曲线。真实固件每秒记录于 `ih_history.c`，屏幕只渲染回放包。

温度页恢复“目标、区域平均、区域最高、区域最低”，三条曲线分别为目标、平均、最高。PA2/PA3 器件温度只保留为未来保护输入，不占用这三项统计。`Workpiece_Submit()` 提交单点温度供总览使用；`Workpiece_SubmitRegion(mean, high, low, tick)` 原子提交完整区域统计，并以平均值更新总览。要求最低≤平均≤最高，拒绝非有限值和越界，过期整组无效。设备/协议未定时 USART2 仍默认关闭；不虚构数据或协议。ADC Watch 为 `dbg_temp1_raw`、`dbg_temp2_raw`、`dbg_temp1_adc_v`、`dbg_temp2_adc_v`、`dbg_temp_valid`。

功率使用同步样本协方差计算，保留方向符号，VA 不能代替 W。`power100` 精度为0.01W；ADC 削顶、过期或错误时显示 `--`，待机采样有效时为0.00W。当前有功功率仍需实板标定，不用于闭环。功率纵轴0～设置上限，温度纵轴0～最高启用温段目标+30℃，频率纵轴为搜频下限～上限；默认仍为1500W、150℃、15～25kHz。曲线端点裁剪到所选范围。

### 每秒记录与视图回放

`HistoryPoint` 一秒一条，仅在成功启动到停止/故障之间记录，存本轮 0～7200s 共 7201 个位置。每次成功启动重开，停止冻结；换页或 HMI 单独重启后从 MCU 回放，MCU 断电和下一次成功启动清除历史。到两小时不覆盖开头，`dbg_history_full=1` 后停止追加。功率历史取整数瓦；实时数字仍为 0.01W。温度历史为 0.1℃，频率历史为 0.01kHz。

温度/功率默认 0～600s，频率/相位默认 0～60s。实时只扩展右端，不向后移动左端；手动范围保留原选择，“恢复实时”回到从 0 开始的全程范围。“冻结显示”保存冻结时刻的历史上界并继续记录，换页后仍按该时刻回放。

隐藏按钮 `bView` 使用参数帧 `A5 5A 02 page field value_le32 FF FF FF`，依次提交 42=起点、43=终点、44=冻结上界（-1实时）、46/47=纵轴下/上限、48=本轮编号，最后45=视图序号（1～65535）。温度使用℃×10、功率W、频率kHz×100、相位°×10；范围和本轮编号都校验通过才接受。这些字段不执行启停/保存。换页或范围变化递增序号，下一次启动递增本轮编号，旧包不绘制。

MCU 每包写 `plotPage/plotEpoch/plotRun/plotYLo/plotYHi/plotReset/plotStart/plotCount` 和最多16个 `cv0～cv15`，最后 `click bCurve,0`。每个非负32-bit值的最高7-bit为秒差（0～127），低三字节为像素高度（0～176，255表示无效并断线）。温度用三通道，其他页面只用第一通道。主控按纵轴范围生成像素，屏幕按回传范围更新刻度；原始每秒记录保留，普通字段刷新不清空绘图。

应用参数不会启动温控或限功率，回执为“目标已应用；温控及限功率尚未启用”。参数只在 RAM 中，掉电恢复默认；方案掉电保存尚未实现。每次完整读取结束前发生编辑、超时或运行状态改变，都不提交部分配置。原有保护参数的 Flash 保存与编号保持不变。提示编号新增 33～35，原 1～32 保持不变。

## 报警记录

`alarmIn` 为报警编号，`alarmOn=1` 表示触发、0 表示恢复；设置 `alarmSec` 后置 `alarmPush=1`，再执行 `click bInput,0`。主控仅上报新增或解除的位，避免每次刷新插入重复记录。

| 编号 | 屏幕含义 | 当前使用情况 |
| --- | --- | --- |
| 1 | 测温数据中断 | 预留 |
| 2 | 锁相失败 | 搜频/锁相/相位信号或调频更新失败，立即停PWM并锁存；旁路继电器保持 |
| 3 | 母线过压 | 已接入 |
| 4 | 母线欠压 | 已接入 |
| 5 | 谐振过流 | 已接入 |
| 6 / 7 / 8 | 功率管 / 整流桥 / 工件过温 | 预留，尚未启用 |

保护页保留六行历史。“确认报警”不解除故障，也不重新启动。加热报警不会释放已吸合的 NTC 旁路继电器。

## 现场故障诊断行

总览和保护页右下角现在显示 `tDiag`。上电无历史故障时为“固件号：110201”；故障后为“驱动后 60ms 原码82/79”这样的首次停机快照。母线恢复后此行不变。请将本次 HEX 与重新编译的本次 V9 一起下载；旧屏幕没有这行诊断，但原业务请求编号仍兼容。

主控回传变量：`fwVersion`、`tripCount`、`tripGate`、`tripMs`、`tripRaw1`、`tripRaw2`。`tripGate=0/1` 表示首次故障时软件驱动使能命令未发出/已发出；`tripMs` 是获准启动到触发的时间（界面上限 99999）；`tripRaw1/2` 是当时 PA7 两次连续注入转换的原始值。这里的驱动状态不是对功率器件实际开关状态的测量。

固件 110202 起，母线改为每轮 32 组同步注入扫描的软件平均。现有 V9 无需重刷，上电无历史故障时会显示“固件号：110202”。故障行的两项原码是 rank1/rank2 各自的平均码；瞬时 rank2 最小/最大值可通过 `dbg_trip_bus_min_raw`、`dbg_trip_bus_max_raw` 查看首次停机快照。欠压检查平均母线，过压检查采样峰值，硬件保护继续有效。

固件 110203 修正 PA7 内部下拉：COMP2 初始化改为模拟模式、无上下拉，并同步 CubeMX 配置。STM32G4 的模拟模式仍允许内部下拉生效，它会对外部模拟采样链构成负载。只更新 HEX，现有 V9 不变；本版不改换算比例和保护门限。需要复测工作状态下 PA7 是否恢复到母线 6.95 V 对应的约 0.740 V。
